## Introducción 

### QUE ES GITHUB 

**Es un sitio web pensado para almacenar nuestros proyectos**,
_con la posibilidad de compartirlos con otras personas (repositorio público), o a nivel personal
(repositorio privado)._

_**Registrarse** en “GitHub” es **totalmente gratuito**. Una vez registrado te **ofrecen** un **almacenamiento limitado** para guardar tus ficheros (unos **500 MB**)_
>limitado por cada mes, con lo que no podemos estar constantemente subiendo y bajando archivos.

_Una vez que nos hayamos creado la cuenta en “GitHub”_, es **muy importante** 
**NO OLVIDAR EL NOMBRE DE USUARIO Y LA CONTRASEÑA.**

### CREAR UN REPOSITORIO EN GITHUB 

_Para crear un nuevo Repositorio lo podemos hacer de varias maneras, pero la más
sencilla es:_ **botón + situado en la parte superior derecha, y clic en New repository**

### AÑADIR ARCHIVOS A NUESTRO REPOSITORIO -

_Para **crear archivos** directamente desde GitHub, pulsamos en **creating a new file**
aparece un **editor online** en el que podemos poner el **nombre del nuevo archivo** y agregar contenido para **guardar** ese archivo pulsaríamos el **botón Commit changes** lo cual **nos crea un nuevo commit** en GitHub_


_Algunos de los **diferentes usos y acciones** que podemos hacer en GitHub de forma resumida son:_

* SUBIR ARCHIVOS DESDE NUESTRO PC CON GIT A GITHUB:

    * git clone https://github.com/ejbarco/ejerciciosJavaScriptDWEC.git


* CLONAR REPOSITORIOS DE GITHUB EN NUESTRO PC:

    * git clone https://github.com/... .git


* ACTUALIZAR UN PROYECTO DESDE GITHUB A NUESTRO PC:

    * git pull

    

* CREAR UNA RAMA NUEVA

    * git branch Rama2


### Conclusiones - 
> github es una buena plataforma para el desarrollo de software que no se queda unicamente en un simple almacen de codigo gracias a su control de versiones y respaldo, colaboracion con la comunidad y visibilidad
